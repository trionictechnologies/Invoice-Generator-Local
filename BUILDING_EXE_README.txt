================================================================================
    WHY CAN'T IT BE BUILT ON LINUX?
================================================================================

PyInstaller creates platform-specific executables:
- Windows .exe needs Windows DLLs and PE executable format
- Linux binary needs Linux .so libraries and ELF format
- They're completely different and not interchangeable

This is NORMAL - all packaging tools work this way.

SOLUTION: Build on Windows (takes 5 minutes total)
