================================================================================
         WHY CAN'T WE BUILD ON LINUX?
================================================================================

PyInstaller creates platform-specific executables:
- Windows .exe needs Windows DLLs and PE format
- Linux binary needs Linux .so files and ELF format
- They are not interchangeable

Cross-compilation is not supported by PyInstaller.
This is normal and expected.

SOLUTION: Build on the target platform (Windows for .exe)
